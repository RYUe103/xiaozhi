# Context索引设计
先使用真实标题路径，页码作为位置元数据，文件名作为不可信标签，页眉页脚不作为章节。不猜主语，不无界跨章节继承；标题边界未知保持unknown。原文与索引文本分离，read/find_exact/引用永远用原文。每向量segment都加同一受限context，保存原文offset。
新版本key包含context算法/输入hash、parser/source/model，确定性标题在请求内完整构建；模型生成索引的完整构建、发布与失败保留旧版本为目标设计，尚未实现。模型context仅独立实验；未来进入索引前必须补齐缓存、预算与错误回退，生成文本永不当引用。
参考Anthropic官方 Contextual Retrieval（2024-09-19）：只采纳上下文前缀用于索引的技术思路，不照搬其外部效果数字。

2026-11-02实际离线对照：91页冻结10题，137标题、640个带上下文块。BM25页级Coverage@20从1.0降为0.95，@40/60均1.0。不是片段Recall，不能宣称提升。确定性上下文默认关闭，模型上下文仅完成独立可行性实验，未进入索引或生产默认。

已完成三段真实Qwen上下文可行性实验，source hash及raw输出保留model-experiment.json；2段通过结构/数字/长度门槛，1段超过100字而拒绝，3段均未进入索引，人工事实复核pending。这不是模型上下文检索收益验证，不部署生成上下文。
