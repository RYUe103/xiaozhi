# 目标架构

每轮深度请求先根据确定性资源范围恢复最近会话文件记录：用户、conversation_id、文件状态、解析代际、来源哈希和权限。恢复只建立轻量持久上下文与来源集合；详细搜索、表格读取和视觉检查仍由模型按工具契约自主调用。

工具暴露链保持 LibreChat 原生实现：资源就绪 -> 请求级读取器绑定到 `toolDefinitions`、`toolRegistry` 和执行回调 -> 模型看到 `tool_choice=auto` -> `ON_TOOL_EXECUTE` 通过同一 Registry 加载 -> Handler 做最终权限/版本校验。没有资源时不暴露读取工具；资源失效时返回明确资源错误。

关键词只保留为查询解析、确定性页码和视觉参数解析，不再决定历史文件是否可访问。
