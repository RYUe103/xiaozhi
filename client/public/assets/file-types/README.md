# 文件类型图标来源

microsoft-word.svg：微软官方 Word 产品页使用的 FY26 Word app icon。
来源页：https://www.microsoft.com/en-us/microsoft-365/word
原始资源：https://www.microsoft.com/content/dam/microsoft/bade/images/icons/en-us/m365-app-icons-fy26/Word-Icon-FY26.svg
获取日期：2026-10-31。保留原始 SVG，不修改路径或颜色；运行时本地加载，不依赖外网。
Microsoft Word 图标属于微软品牌资源，此处用于标识用户生成的 Word 文档类型，不代表产品为微软官方服务。


## 统一文件类型图标（2026-10-31）

- Excel、PowerPoint：微软官方 Microsoft 365 FY26 应用图标，与 Word 同系列。
- PDF、图片、压缩包、CSV、TXT、Markdown、代码、音频、视频、通用文件：微软 Fluent 文件类型图标，来自官方 Office CDN 的 48px SVG 原始资源。
- 官方 Fluent 图标实现：https://github.com/microsoft/fluentui-system-icons/tree/main/packages/react-icons-file-type
- CDN 版本与逐项原始 URL 见 sources.json；来源以官方 useFileTypeIcon.tsx/constants.ts 为依据。
- JSON 与其他代码文件共用 code.svg，未知文件使用 genericfile.svg；SVG 原样保存，本地离线加载，不新增运行时依赖。
